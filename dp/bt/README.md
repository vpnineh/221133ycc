# DonchianProp Portfolio v13.13 — اکسپرت نهایی + سیستم کامل بک‌تست

این بسته شامل آخرین نسخه‌ی پایدار ربات (v13.13) و هارنس C++ است که همان سورس MQL5 را روی داده‌ی M1 اجرا می‌کند و تستر MT5 را در حالت «1 minute OHLC» شبیه‌سازی می‌کند. **داده‌ی قیمت داخل بسته نیست** (حدود ۳ گیگابایت)؛ با اسکریپت‌های `data/` دوباره ساخته می‌شود.

> شبیه‌ساز برداشت ماهانه **داخل ربات نیست**. فقط در هارنس (کلیدهای `PAYD/PAY1/PAYB`) وجود دارد. ربات روی حساب واقعی و در Strategy Tester هیچ برداشتی انجام نمی‌دهد.

## ۳) اجرای ربات در MT5
1. فایل `ea/DonchianProp_Portfolio_v13_13.mq5` را در `MQL5/Experts` بگذارید و **یک بار در MetaEditor کامپایل کنید** (F7).
2. Strategy Tester: مدل `1 minute OHLC`، نماد چارت XAUUSD، ورودی‌ها پیش‌فرض. `InpTesterChain = true` باعث می‌شود تستر بعد از رسیدن به هدف، فاز ۲ و سپس حساب فاند را خودش ادامه دهد.
3. `InpDemoMode` فقط برای نمادهای custom (مثل `XAUUSD-back`) است؛ روی سرور FundedNext و حساب واقعی **خاموش** بماند (پیش‌فرض خاموش است).
4. بالانس تست را برابر حساب واقعی بگذارید. اگر ۱۰ هزار است، خط `SMALL ACCOUNT` را در ژورنال ببینید.

## ۴) پیش‌نیازهای سیستم بک‌تست
- لینوکس یا macOS، `g++` با C++17 (نسخه‌ی ۹ به بالا)
- Python 3.9+ با `numpy`، `pandas` (و `openpyxl` برای خواندن xlsx تستر): `pip install numpy pandas openpyxl`
- حافظه: یک اجرای ۱۰ ساله حدود ۴ گیگابایت RAM و ۳ تا ۵ دقیقه زمان می‌گیرد. اجرای ۲۴ ماهه حدود ۱.۵ گیگابایت. تعداد اجرای موازی را با RAM تنظیم کنید.

## ۵) ساخت داده
```sh
data/build_data.sh 2013                 # دانلود HistData، ساخت data/bin/<SYM>_m1.bin، گزارش data/qa_report.txt
cd data/bin && sha256sum -c ../MANIFEST.sha256   # مقایسه با بیلد مرجع
export DATADIR=$PWD/                    # مسیر داده برای هارنس (با / در انتها)
```
- HistData داده‌ی Bid با ساعت EST بدون DST می‌دهد؛ `build_bin.py` آن را به ساعت انگلستان تبدیل می‌کند و هارنس به ساعت سرور برمی‌گرداند.
- **US30 در HistData نیست:** خروجی M1 آن را از MT5 بگیرید و با `data/scripts/us30/dji_clean.py` تبدیل کنید (فرمت ۴۰ بایتی: int64 زمان + float64 برای o,h,l,c).
- برای بازه‌ی ۲۰۱۰–۲۰۱۵ (آزمون داده‌ی کنار گذاشته) همان اسکریپت را از سال ۲۰۰۹ اجرا کنید و در یک پوشه‌ی جدا بسازید.
- `tools2/hd.py OUTDIR SYM Y0 Y1` دانلودگر مستقل HistData برای نمادهای دیگر است.

harness/build.sh v1312 --conv     # نسخه‌ی قبلی برای مقایسه

اگر ربات را تغییر دادید، `ea.mq5` تازه را در `harness/ea/v1313/` کپی کنید و دوباره با `--conv` بسازید. کلیدهای محیطی ورودی‌ها در `harness/ea/v1313/inputs119.h` هستند.

## ۷) اجراها
همه‌ی اجراها: `harness/run.sh VER NAME @PROFILE KEY=VAL ...` ← خروجی در `$OUTDIR` (پیش‌فرض `out/`): `NAME_deals.csv`، `NAME_eq.csv`، `NAME.log`.

**الف) حساب فاند ۱۰ ساله (۲۰۱۶–۲۰۲۶):**
```sh
harness/run.sh v1313 fund @CALR PRESET=2 BAL=100000
python3 tools2/summ.py out fund          # CAGR، افت، بدترین روز، شارپ، بازده هر دوره
python3 tools2/fund.py out fund          # ٪ در ماه، پنجره‌های ۱۲ ماهه، احتمال رسیدن به −۹٪
```
**ب) هزینه‌ی دوبرابر (آزمون فشار):** همان دستور با `COSTX=2`.

**ج) برداشت ماهانه‌ی کل سود (واقعیت FundedNext؛ فقط هارنس):**
```sh
harness/run.sh v1313 pay @CALR PRESET=2 BAL=100000 PAYD=30 PAY1=30 PAYB=0
python3 analysis/pay.py out pay          # ٪ در ماه با احتساب برداشت، کمترین اکوییتی، روزهای بد
```
`PAYD` = فاصله‌ی برداشت (روز)، `PAY1` = روز اولین برداشت، `PAYB` = درصدی از سود که در حساب می‌ماند (۰ = همه برداشت). در لاگ: `{"payouts":N,"withdrawn":X}` و ستون `wd` در فایل eq.

**د) ۳۹ حساب فاند تازه × ۲۴ ماه با برداشت ماهانه:**
```sh
python3 tools2/mkfresh.py mf > jobs_mf.txt
python3 tools2/runner.py jobs_mf.txt out/mo 3 v1313 @CALR BAL=100000
python3 analysis/ld.py out/mo mf         # کمترین اکوییتی، دم ضرر روزانه، ٪ در ماه، بدترین حساب
```
**ه) چالش (۳۹ شروع فصلی، زنجیره‌ی فاز ۱ ← فاز ۲ ← فاند):**
```sh
python3 tools2/chjobs.py ch > jobs_ch.txt
python3 tools2/runner.py jobs_ch.txt out/ch 3 v1313 @CALR BAL=100000
python3 tools2/chabandon.py out/ch ch    # میانه/p75 روز، P(≤90 روز)، تلاش‌ها
CHDIR=out/ch python3 analysis/chj.py ch  # هدف J = روز تا فاند + هزینه‌ی تلاش‌ها
CHDIR=out/ch python3 analysis/lc.py ch out/mo mf   # اقتصاد کل چرخه (چالش + فاند، سهم ۸۰٪)
```
`runner.py` اجراهای تمام‌شده را دوباره اجرا نمی‌کند؛ اگر قطع شد، همان دستور را دوباره بزنید. عدد سوم تعداد اجرای موازی است.

**و) حساب کوچک / تکرار تست شما:**
```sh
harness/run.sh v1313 c10k @CALR PRESET=0 LOUD=1 BAL=10000 FROM=1704067200
grep "STAGE SUMMARY\|SMALL ACCOUNT" out/c10k.log
```
گزینه‌ی حساب ۱۰ هزاری: `MLOR=2.0` (معادل `InpMinLotOverRisk`).

### کلیدهای مهم
| کلید | معنی |
|---|---|
| `PRESET` | ۰ = زنجیره‌ی چالش از فاز ۱، ۲ = حساب فاند |
| `BAL` | بالانس اولیه |
| `FROM` / `TO` | بازه (epoch ثانیه، UTC). مثال: 2024-01-01 = 1704067200 |
| `PREDAYS` | روزهای داده‌ی قبل از شروع برای اندیکاتورها |
| `COSTX` | ضریب هزینه (۲ = دوبرابر) |
| `LOUD=1` | چاپ کامل ژورنال (برای چالش و تشخیص) |
| `RF`، `MLOR`، `MAXRT`، `ROOM`، `VF` | ریسک فاند، حداقل لات/ریسک، سقف ریسک هر معامله، اتاق روزانه، فیلتر نوسان طلا |
| `OVR=P.7=0.15,SLK.3=1.5` | تغییر پارامتر اسلیو (شماره‌ی اسلیو بعد از نقطه) |
| `PAYD/PAY1/PAYB` | شبیه‌ساز برداشت (فقط هارنس) |

### پروفایل‌ها
| پروفایل | کاربرد |
|---|---|
| `CALR` | **پیش‌فرض تحقیق:** هزینه‌های FundedNext + لغزش ۰.۵×اسپرد، پرشدن در گپ، اسپرد رول‌اور |
| `CAL` | هزینه‌ها مثل تستر FundedNext، بدون لغزش |
| `FNT` | تکرار دقیق تستر FundedNext (جدول تاریخچه‌ی اسپرد) |
| `MQ` | تکرار تستر MetaQuotes-Demo (فقط برای مقایسه) |
