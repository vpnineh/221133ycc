  Rule (deterministic, no look-ahead): per-sleeve carry c_k (persisted). Exact lots x = risk_money / loss_per_lot.
  Only when x < N*step (N = 5; at 100k no sleeve is below this, so 100k must stay trade-for-trade identical):
    if x < vmin: frac = x / vmin; hard cap unchanged (min-lot risk <= InpMaxRiskPerTradeR x base risk, else refuse);
                 c_k += frac; if c_k >= 1: trade vmin, c_k -= 1; else skip ("min-lot dither").
    else: base = floor(x/step)*step, frac = (x-base)/step; c_k += frac; if c_k >= 1: base+step (only if its risk <= MAXRT x base), c_k -= 1.
